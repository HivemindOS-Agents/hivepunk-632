Framework aimed to provide useful TypeScript decorators to implement controllers, services and request handlers, built with Fastify. It advertises Fastify compatibility, JSON Schema validation, high performance, customisation, 100% TypeScript, plugins and simple dependency injection, and requires experimentalDecorators in TypeScript config.
