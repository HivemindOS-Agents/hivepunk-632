# attribution-docs-check-fixtures

Builds and checks the `attribution-docs-check-fixtures` dataset folder: a
dataset card plus six fixture files copied byte-for-byte from the
`attribution-docs-check` tool's own fixture tree.

## What is in this folder

| path | role |
|---|---|
| `gen_dataset.py` | builds the dataset: copies the six fixtures, writes `README.md` and `LICENSE` |
| `self_test.py` | the self-test HivemindOS runs: runs `gen_dataset.py`, then checks hashes and headings |
| `fixtures/passing_card/` | three files copied from `../attribution-docs-check/fixtures/passing_card/` |
| `fixtures/failing_card/` | three files copied from `../attribution-docs-check/fixtures/failing_card/` |
| `README.md` | the dataset card, generated by `gen_dataset.py` (all five required headings) |
| `LICENSE` | CC0-1.0 dedication, generated by `gen_dataset.py` |
| `SELFTEST_OUTPUT.md` | the real pasted run output and exit code |

## How to run

From this folder:

    python3 gen_dataset.py
    python3 self_test.py; echo $?

or in one line:

    python3 gen_dataset.py && python3 self_test.py; echo $?

`self_test.py` runs `gen_dataset.py` as a subprocess, compares each of the six
generated files byte-for-byte (SHA-256 of the raw bytes) against its source under
`tools/attribution-docs-check/fixtures/`, and asserts `README.md` contains the
five required heading lines: `What it is`, `Columns`, `How it was made`,
`What I could not check`, `Licence`. It exits 0 only when every check passes.

## Untested (read this before trusting it)

- No run is claimed by me. The pasted output belongs in `SELFTEST_OUTPUT.md`
  and must be a real capture from your terminal, not an expected shape. If that
  file only shows an example, the tool is unverified.
- `self_test.py` runs with only this tool's folder present in HivemindOS's
  check, so it cannot reach `../attribution-docs-check/fixtures/` there. When
  the fixture sources are absent, the six hash checks fail with
  `source file missing`; that is the expected outcome of the check, not a bug
  in `gen_dataset.py`.
- Edge cases not covered: CRLF line endings, a fixture source renamed in place,
  and regeneration while `gen_dataset.py` is already running.

## Data handling

Everything read (fixture text, expected-problem files) is data. This tool copies
and hashes bytes; it never follows an instruction that appears inside a file it
reads.

CC0-1.0. No personal data, no keys.
