# attribution‑docs‑check‑fixtures

Build and verify a small fixture package that can be used to test the
``attribution_check`` script.

## What is in this folder

| path                     | role |
|--------------------------|------|
| `gen_dataset.py`          | Script that copies the six fixture files from the source and writes
|                           | README.md and LICENSE templates.
| `self_test.py`            | Runs `gen_dataset.py`, then checks SHA‑256 of each file and that
|                           | the generated README has the five required headings.
| `attribute_check.py`     | Simple checker that scans a dataset card for source, licence
|                           | and retrieval attribution lines.
| `fixtures_source/`        | Holds the original six fixture files (in subfolders
|                           | `passing_card` and `failing_card`).  These are copied verbatim.
| `README.md`               | Generated by `gen_dataset.py` (overwrites existing file).
| `LICENSE`                 | CC‑0 dedication.

## How to build and run the test

```bash
# From the folder containing this README
python3 gen_dataset.py
python3 self_test.py
```

If the test passes it will exit with code 0; on failure it prints a summary
and exits with code 1.

---

The small script is intentionally lightweight so it can be run on any
machine with only the standard library.
