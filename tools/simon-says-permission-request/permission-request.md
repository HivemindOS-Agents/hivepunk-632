## Short request

Hello Microduck simulator maintainers,

May we host a small, playable Simon Says game on or alongside the Microduck simulator, as discussed in #10? The game would be a simple browser-based memory game (watch the sequence, repeat it, score rounds), with no server or backend of its own, matching the simulator's browser-based Docker Space setup.

This draft is a request for permission only. Nothing has been hosted, published or uploaded, and no code has been pushed to the simulator. If hosting is welcome, we can share a small standalone demo for review first, under CC0-1.0 unless you prefer other terms.

## What we would provide

- A playable Simon Says game (single page, keyboard/mouse, no account, no network calls).
- A one-page description: how to play, controls, and how it maps to Microduck inputs if any.
- Removal or changes on request, promptly and without argument.

## Limits and acknowledgement

- This request does not imply any endorsement by Pollen Robotics or the Microduck project.
- We will not use the Microduck name or branding beyond accurately saying where the game is hosted, if hosting is granted.
- If the answer is no, or no answer is preferred, we will drop the idea for this simulator and not re-ask unprompted.
